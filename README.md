# График работы бригады — демо

HTML/CSS/JavaScript-прототип листа «Б1 + Бригадир + Осн Напарник» с правилами листа «График Бригады».

**Демо:** https://user14052020.github.io/work-schedule/
**Вход:** `admin` / `admin` — поля уже заполнены.

## Что работает

- Таблица с цветами ролей, блоками смен, объединенными итогами и горизонтальной прокруткой.
- Отдельные меню «График бригады», «Сотрудники», «Справочники».
- 13 вымышленных сотрудников, справочники должностей, видов работ, статусов, счетов, базовых ставок и объектов. Коды и основные правила взяты из ТЗ; имена, контакты и объекты заменены демонстрационными.
- Выбор состава из сотрудников группы «Поля» и применение к любому диапазону дат выбранного месяца. Изменение отдельных смен; два сотрудника в «Доп. №2».
- Редактирование всех ячеек с данными; справочные значения проверяются по спискам. Сотрудник задания наследуется из смены: его можно убрать/вернуть, а заменять сотрудника нужно в составе смены.
- Сотрудники автоматически участвуют в работе при заполненном виде и статусе РД/ДЕЖ; часы сотрудников учитывают отдельные исключения.
- Сворачивание дня, всех показанных дней и месяца. Месячные итоги остаются видимыми. При входе показывается весь месяц: все дни свернуты, текущий день раскрыт и виден сразу. Дата определяется по локальному календарю браузера; если она вне месяца графика, все дни остаются свернутыми.
- Пять начальных строк в смене и добавление по две; отдельная форма добавления работы.
- Вставка прямоугольного TSV-диапазона из Excel/Google Sheets в ячейку, включая многострочный текст и двух сотрудников Доп. №2. При ошибке весь диапазон отклоняется.
- Автоматические итоги часов, статистика по видам (без нулей, по убыванию), предварительная базовая зарплата. Ручное изменение часов/зарплаты помечается; очистка ячейки возвращает формулу.
- Локальное сохранение, отмена последней правки, сброс примера и XLSX для Excel с тремя листами, цветами, объединенными итогами и группировкой дней. Экспортируются все дни выбранного месяца, состав/статусы смен и задания; суммы смены не дублируются в каждой строке.

В шапке выбираются месяц и год. **Все 30 дней сентября и 31 день августа 2026 года заполнены вымышленными работами**; месяцы отличаются составами смен, объектами, заданиями и итогами. Данные и правки хранятся отдельно для каждого месяца, сотрудники и справочники общие. Остальные месяцы создаются как пустые календари с правильным числом дней, включая високосный февраль. По умолчанию открывается сентябрь 2026; период применения состава всегда охватывает выбранный месяц. Первые две смены сентября сохраняют пример из ТЗ (11 и 10,5 часа). Старые сохраненные правки сентября переносятся при обновлении.

## Границы демо

Это приложение с фиксированными правилами графика, а не полноценный Excel: нет произвольного языка формул, перетаскивания диапазонов, импорта XLSX, годовых архивов и общего серверного хранения. XLSX содержит снимок значений на момент выгрузки; формулы приложения в нем не исполняются. «Активен» в справочнике сотрудников управляет новыми назначениями, а не реальным доступом к системе.

Авторизация демонстрационная: все исходники и начальные данные публичны. Изменения принадлежат текущему браузеру и не синхронизируются между устройствами. Не вводите сюда реальные персональные данные клиента. В репозиторий и в Pages не включен исходный XLSX.

Зарплата — только базовые ставки по часам каждого сотрудника и водительскому признаку. ОТП использует отдельную ставку; остальные нерабочие статусы в демо дают ноль. Часы от нуля до 24 допускаются с шагом четверть часа. Доплаты бригадиру, обучение, распределение премий/штрафов и выплаты через три дня не реализованы; их правила требуют согласования. Денежная корректировка хранится отдельно от базовой суммы. Ставки и водительский признак общие: их изменение влияет на автоматический расчет во всех месяцах при открытии и экспорте; для рабочей версии нужны тарифы с датой действия.

Изменение объекта в справочнике обновляет связанные поля графика только если они еще совпадают со старым значением; ручные дополнения сохраняются. Переименование используемого кода запрещено, чтобы не разорвать ссылки. Служебные коды закреплены за правилами.

## Локальный запуск

Из корня репозитория:

```text
python -m http.server 4173 --bind 127.0.0.1 --directory public
```

Открыть http://127.0.0.1:4173/. Сборка не нужна. ExcelJS 4.4.0 (MIT) включен в public/vendor и загружается локально по нажатию экспорта; внешнего CDN при работе нет. Из-за ES-модулей нужен HTTP-сервер, а не открытие `index.html` через `file://`.

Проверки расчетов и связей:

```text
node --test tests/*.test.mjs
```

## Публикация

`main` содержит исходники, тесты и документацию. GitHub Pages раздает только содержимое `public/`, вынесенное в ветку `gh-pages`:

```text
git subtree split --prefix public -b gh-pages
git push origin gh-pages
```

В настройках Pages: Deploy from a branch → `gh-pages` → `/ (root)`. `.nojekyll` отключает обработку Jekyll. Все ссылки на ресурсы относительные и работают в подпапке `/work-schedule/`.
